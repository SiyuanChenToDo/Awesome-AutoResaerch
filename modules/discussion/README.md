# SAGE 多角色讨论 · discussion

实际实现位于 [sage/discussion](../../sage/discussion/)，将 CoI 的文献演化链和 Agent Laboratory 的博士生/博士后讨论机制结合。运行时不导入上游快照。

- 每位博士生拥有一条独立 CoI 文献链、至少一个区别于其他角色的来源，以及原始候选副本。
- 角色分别关注方法机制、评价反例、迁移鲁棒性、可复现性；角色数量为 2–4，讨论轮次为 1–3。
- 环形互评基于本轮开始时的候选快照，避免后发角色偷看本轮修订。
- 意见分为有来源支持的模型判断、未知或失败；未知/失败意见不能直接被采纳。
- 修订必须记录采纳/拒绝、原因和来源，并保留过去已经采纳的要求。
- 博士后选择修订后的候选，将已采纳意见转为实验计划要求；规划输入、最终计划和下游代码生成保留该交接。
- 修改后的想法重新做新颖性检索，不沿用旧判断。

`discussion-mode none` 保留原流程；`hybrid` 开启新流程。提示词有固定版本与哈希，所有调用仍消耗共享 Runtime 预算，不提供无界自优化。

验证范围：来源 ID 归属与结构一致性、修改对计划的数据影响、有限循环和下游衔接。有效来源 ID 不证明文本真的支持该意见，同一模型扮演多个角色也不是独立科学验证。合成样例不证明真实讨论质量。
