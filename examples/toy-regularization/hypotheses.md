## H-001：性能假设

在 README 指定的合成分布下，Ridge(λ=0.1) 相对 OLS 的平均 MSE 改善至少 0.05。12 个预定数据种子成对比较，效应以 OLS−Ridge 计算。

- 支持：预定 95% 区间下界超过 0.05。
- 不支持最低效果主张：上界低于 0.05。
- 不确定：区间包含 0.05，或完整配对数不足。
- 无效：数据、评分器或实现存在使比较不可解释的错误。
- 潜在解释 A：正则化减轻对训练噪声的敏感性。
- 潜在解释 B：目标函数缩放或预处理实现差异造成表面改善。
- 辨别检查：训练专用预处理、目标函数尺度测试、相同精度和稳定求解器；附系数范数和强弱惩罚消融。

这些检查仍不能完整证明机制 A。机制与泛化到真实数据的声明均不在本轮确认性范围内。假设尚未测量，关联声明 CLM-001 状态为 proposed。
