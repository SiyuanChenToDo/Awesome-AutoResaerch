# 示例：固定正则化能否改善合成回归？

**这是未执行的教学计划。没有生成数据、训练模型、运行评分器或得到实验结果。** `status=draft`，真实代码提交、数据指纹、评价器哈希、批准人和时间为空。它演示如何写清研究契约，不能作为 Ridge 有效或本仓库能自动研究的证据。

## 问题与假设

在下面固定的小样本、有噪声合成线性回归中，固定 λ=0.1 的 Ridge 相对 OLS，能否使平均测试 MSE 降低至少 0.05？该阈值只用于教学，不代表任何真实应用价值。

这不是新算法研究，也不声称创新。目标是用一个易理解的例子练习基线、单变量干预、配对重复、消融、负结果和证据账本。

## 预定数据与方法

- 特征维度 32；每个数据重复独立生成训练集 64 行、最终测试集 4096 行。
- 特征 x 服从均值 0 的多元正态，协方差 Σ[i,j] = 0.8^|i−j|。
- 真实系数前 8 项为 1/√8，其余为 0；y = xβ + ε，ε 独立服从均值 0、标准差 2 的正态分布。
- 每列仅用训练均值和标准差标准化；测试使用同一训练参数，不能重新拟合预处理。截距不正则化。
- OLS 使用 SVD 类稳定解法。Ridge 目标为“训练残差平方的平均值 + λ × 系数平方和”；将来实现必须测试库的正则化系数是否与此定义等价。
- 主比较固定 λ=0.1；λ=0.01 与 λ=1.0 是探索性强度消融，不能据此选择新主候选。
- 正式种子为 101–112，共 12 个独立数据重复；每个种子内四种方法使用完全相同数据。生成器以明确子流区分训练特征、训练噪声、测试特征和测试噪声。
- 冒烟测试种子为 11、12、13，不与正式数据重合，不用于选择 λ。

## 预定统计决策

每个种子计算 d = OLS MSE − Ridge(0.1) MSE；正数表示改善。以 12 个数据重复为独立单位，报告所有 d、平均 d 和自由度 11 的双侧 95% t 区间。

- 区间下界 > 0.05：在这套合成分布与预算内支持最低效果假设。
- 区间上界 < 0.05：不支持“至少改善 0.05”；若上界 < 0，还支持方向相反。
- 区间包含 0.05：不确定；不能延长采样直到出现期望结论。
- 少于 12 个完整主比较配对：保留结果，但确认性结论为不确定。
- 数据泄漏、实现错误或评分器改动：相关结果无效，和科学负结果分开。

t 区间的小样本假设可能不适合偏斜很强的差值分布。该风险在实验前公开；不按观测结果换统计方法。消融仅作描述性分析，不能悄悄增加确认性检验。区间只描述此生成分布下数据重复的不确定性，不覆盖真实数据分布变化。

## 预算与隔离

离线 CPU、无 GPU、无付费 API，总墙钟上限一小时。12 次冒烟拟合 + 48 次正式拟合 + 最多 6 次重试 = 66 次；单次拟合最多 30 秒。数据生成、分析和失败都计入总时间。只有基础设施中断可按原配置重试，每次最多重试一次、全局最多六次。

正式评价仅一个批次，冻结后同时评估四种方法。代码和数据尚未存在，真实隔离也尚未实现；公开种子意味着本例不是防污染基准。若用于练习严格分工，应由单独账号保管最终数据和评分器。

2. 实现和测试数据生成、训练及评分器；审查数值约定和路径权限。
3. 固定依赖、代码提交、数据清单、校验和与硬件。
4. 在正式结果出现前冻结协议；记录外部决策与计划哈希。
5. 通过真实执行器运行，追加全部尝试；当前仓库未提供此训练实现。
