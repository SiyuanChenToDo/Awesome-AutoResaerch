# SAGE 视觉资产

SAGE = Scientific Agent for Grounded Exploration（基于证据探索的科研智能体）。

| 文件 | 用途 |
|---|---|
| [sage-icon.svg](sage-icon.svg) | 128 × 128 图标，适合头像或紧凑位置 |
| [sage-logo.svg](sage-logo.svg) | 720 × 176 完整标志，包含英文全称 |
| [sage-hero.svg](sage-hero.svg) | 1200 × 440 仓库 README 横幅 |

图形为本仓库原创的可编辑 SVG：S 形路径把三个证据节点串联，暖金色端点代表下一步探索。深绿色、浅鼠尾草色和象牙白构成固定底色，在 GitHub 浅色、深色主题中保持一致对比度。横幅中的文献卡与提案只是概念示意，未呈现实验数据或研究结果。

- 直接编辑 SVG 中的路径、文字和颜色即可；无需构建工具或图像生成服务。
- 不嵌入位图、脚本、外部字体或远程资源。文字使用系统无衬线字体，附有 `title` 和 `desc`。
- 保留 `viewBox` 与宽高比，图标建议显示宽度不低于 24 px；完整标志建议不低于 320 px。
- 图标符号在三个文件中使用相同几何形状；修改符号时同步这三个文件。
- README 通过相对路径引用横幅；中文介绍与状态信息也以正文提供，不依赖图片阅读。
