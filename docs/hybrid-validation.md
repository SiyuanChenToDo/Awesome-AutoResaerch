# CoI 博士生讨论 × Laboratory：验证记录

日期：2026-10-17。对象为本仓库 SAGE 衍生流程，不是两个原始项目的论文结果复现。固定提示词版本为 v2；真实模型质量尚未测量。

## 可复现命令

```bash
python scripts/check.py
python -m unittest discover -s tests -p test_discussion_independent.py -v
python -m unittest discover -s tests -p test_hybrid_reviewed_subprocess.py -v
python -m sage laboratory --mode offline --discussion-mode hybrid --backend fixture --allow-execution --output projects/hybrid-check
```

每次 CLI 测试应使用新输出目录。fixture CLI 不执行任意 Python；实际子进程测试单独只允许两个逐行审查的固定脚本。

## 验证到的功能

- 关闭讨论仍走原提案路径，不产生隐式讨论调用。
- 每位博士生保留不同来源范围、独立记录与原始候选快照；重复来源组合或不足人数不能假装形成多方讨论。
- 互评意见必须使用该角色可引用的来源 ID；错误 ID、重复 JSON 字段、非法状态和无效结构均不能直接通过。
- 未知或失败意见不能被当作已支持意见采纳；保留拒绝与不确定性。
- 修改或移除意见会改变修订、博士后选择与实验规划输入，验证的是数据依赖而非装饰性的对话记录。
- 采纳要求、其来源和已有的证据卡片交给规划；多轮修订不能静默抹掉先前采纳的要求与来源。
- 修改后的候选重新检查相似工作，不沿用修改前的新颖性判断。
- 规划交接进一步进入代码生成和各章节写作输入；不把模型讨论内容伪装成已测量结果。
- 角色、轮次、重试均有限；提案、讨论、代码和报告共用同一个 Runtime 预算，不在阶段交接时重置。
- 提示词固定版本、模板/结构哈希和输入哈希进入记录；没有无界自修改提示词。

引用归属校验不证明来源在语义上支持结论，保留的快照也不构成不可篡改存储。角色使用同一模型不构成独立专家验证。

## 合成提案链对照

使用相同合成主题、输入来源、全新 fixture 提供方、默认预算上限。仅改变 discussion_mode：

| 观察项 | none | hybrid（2 人、1 轮、v2） |
|---|---:|---:|
| 模型接口调用次数（假模型） | 44 | 55 |
| 检索接口调用次数（假来源） | 15 | 17 |
| 预留最大输出 token | 88,000 | 110,000 |
| 被选择候选（零起始） | 0 | 1 |
| 讨论衍生规划要求 | 无 | 加入匹配预算消融，区分方法变化与搜索投入 |
| 流程状态 | completed | completed_with_uncertainty |

合成样例中一条意见有明确引用范围，另一条关于迁移收益的意见缺少依据，因此 hybrid 保留不确定状态。选择变化来自写明的 fixture 决策规则，**不能说明候选 1 更有科研价值**。

两组是相同预算上限，实际调用数不同；新增 11 次模型接口调用、2 次检索和 22,000 预留 token。这里没有真实模型 token 计量或美元费用，也不是等算力质量实验。

## 实际 Python 子进程测试

[test_hybrid_reviewed_subprocess.py](../tests/test_hybrid_reviewed_subprocess.py) 经过真正的 run_laboratory 注入临时测试后端：

- 只接受两个独立列明、逐行审查过的固定源码字符串；其他源码在启动进程前拒绝。
- 只将固定输入路径替换为测试创建的临时文件；不加载真实研究数据或凭据。
- 使用 Python 隔离导入模式、精简环境和 5 秒超时；没有安装依赖或启动 Docker。
- 两个真实进程退出码均为 0，预测分别为 `[0,1,2]` 和 `[0,2,4]`。
- 固定宿主评价器计算合成标量 MSE 为 5/3 和 0，选中 attempt-2；报告仍标注 synthetic fixture 和 scientific_validation: not_performed。

这确认受审查脚本的执行反馈能与讨论、方案和报告串联，不验证任意模型代码的安全性，也不等于实测 Docker 执行后端。
