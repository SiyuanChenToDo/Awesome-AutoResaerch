# 写作链修复与验证：2026-10-18

## 发现的问题

原运行完成了八节初稿、模型审稿和修订调用，但修订文本中出现了给作者的编辑指令，而非实际替换正文。最终模型仍要求修改，软件状态却容易被解读成论文已经写好。完整报告与研究有效性也不能由模型评分证明。

## 已修复

- 章节与修订提示明确要求作者口吻的实际正文、精确字段和最终替换段落；针对真实观察到的编辑指令加入有限格式检查及字段反馈。该启发式不保证语义正确。
- 独立 `draft_readiness` 保留 `revision_required`、`draft_for_human_review` 或 `incomplete`，与调用链 `status` 分开。
- `sage write-report` 核对父运行全部 manifest 文件、方案/策略/评分绑定、固定评分程序与重算统计后，才发送写作模型请求。支持新写作源码接续旧实验，分别记录两个源码身份，不篡改原运行。
- 写作上下文补充真实实现、选中策略、有限探针的严格判定和未执行控制；草稿附加程序生成的数值表及实现说明。零容差下两个探针分支的同一性被明确解释。

## 真实验证

写作续跑使用既有确认结果，真实请求模型 12 次，SDK 记录 217,657 token，生成八节实际段落。新检索、训练与最终测试启动数均为零。原实验文件保持不变。两轮候选修订没有提高当前模型评分，原稿及所有候选保留；软件结束时仍诚实标记 `draft_readiness=revision_required`。

随后进行局部写作与事实表达校正，保留独立编辑差异记录：区分哈希检索条件与全局语义条件，区分训练输入与验证探针，收紧部分阅读范围下的文献声明，解释严格零容差的浮点事件，并从冻结分析填入正文数值。该编辑版本没有获得新的独立科学评分。原始模型输出与编辑版本分别保存在私有项目目录。

407 项离线测试通过，包含新增的编辑指令拒绝、未解决审稿状态、路径逃逸、原始数据篡改、策略绑定、统计不一致与评分程序变化检查。默认离线模式不产生模型费用。研究正文、原始模型回复和数值结果不提交到公共仓库。

这是试验报告草稿的工程与写作修复。完整研究控制、统计功效、外部数据评价、独立科学审稿和投稿稿件准备仍需另行完成；不得将流程完成、局部编辑或模型评分当作这些工作的通过证明。
