## 实际执行结果

冻结的合成开发任务包含 96 个表达式与 16 个数值探针。未简化基线的平均节点压缩为 0；候选脚本为约 0.5431，两者均没有探针上的数值差异。

这只是接口验证子任务：候选脚本实现精确的局部代数重写，不是生成提案中完整的哈希/碰撞审计研究方法。探针一致也不证明符号恒等，不能把该分数当作真实论文改进、独立 benchmark 或全球创新。

另一次负向验证中：错误长度输出标为 `invalid_output`；错误语义产生 995 次探针差异并不给有效成绩；无限循环受 CPU 上限终止，退出码为 -9。基线、失败与成功全部计入尝试记录；不会把失败变成零分有效实验。

候选以 nobody（UID 65534）执行，不继承 API 凭据。采用独立、非 root 可执行的 Python 及资源上限。没有网络沙箱，因而当前入口仍仅支持经过审查的 smoke 脚本。

## 联网范围与失败记录

本轮首次新联网检索收到 arXiv HTTP 429，未取得重试时间，原运行保留失败并停止新检索。后续显式选择固定真实论文语料：五篇之前实际取得、核对正文/片段哈希的 arXiv 文献。模型调用是真实的，文献检索范围是本地固定语料，不能宣称本轮完成最新文献查新。

失败试跑均保留。实际修复包括：查询数量的字段级反馈；重排理由由控制器生成有标记预览并保留完整文本；查新保留提供方候选而不先由生成模型筛掉；桥接模块名遮蔽原版包；root 目录解释器不能被降权用户执行。模型输出的 Python fence/纯代码采用显式格式适配，保留原始回复及失败状态，而不是把原 API 调用重新标记成功。

早期一次代码生成辅助脚本在异常后未保存 SDK token 明细，已记录此缺口；之后的辅助脚本无论成功失败均保存审计和消耗。因此这里只报告最终完整运行的准确消耗，不宣称全部历史 token 账本完整。
