# 原生评分与修订链修复

历史四研究者运行验证了协作动作，但其科学评分使用自写整体0–1提示，没有接入ARIS原七维。原始运行、历史0.44/0.41与科研文件保持原样；新评分口径不与旧分数直接比较。

## 采用原始提案量表

[原版四项目rubric对照](upstream-review-rubrics.md)列出来源、固定提交、尺度、权重和旧接线。当前原生评分采用ARIS `research-refine` 的七维1–10分，权重15/25/25/15/10/5/5%，而不是将Agent Laboratory成稿量表直接套给未做实验的猜想。完整原skill与taste-calibration依赖现均交付给研究者。

每位入选候选得到七维分数和理由，低于7分须给具体弱点、修复方法及优先级。程序计算加权分÷10，再对入选候选等权平均；候选间平均和CORAL归一化是SAGE适配。没有人工整理的3好3差参考例，明确 `calibration: none`，不编造标定样本。READY仍是建议性意见，同家族API不构成独立验收。

## 修复的实际路径

- 数值评阅不再接收历史分数、作者修复自评和调用者focus。原始文件保留在私有审计中，真正送出的科学投影与证据另行记录。
- 仅评selected候选，held/rejected台账单列，不混入入选总分。候选、来源、逐维理由、修复字段和存活ID均严格验证；旧的缺字段回复不能成为有效评分。
- 程序按固定权重汇总，不采纳模型直接给出的整体浮点分。高优先级阻断意见未解决时不能同时宣称同一候选READY。
- 问题忠实度对照管理器冻结的初始problem，而非作者后来改写的anchor；早期尚未冻结则明确标注未核。允许有理由的科研转向，但必须报告漂移。
- 团队正式评分要求至少两次协调者综合谱系的建议性评阅，且至少一次覆盖当前精确文件。早期研究者批评、正式grade和未登记版本的旧评语不能充数。
- 每条同伴意见明确target_fields。只改无关风险或重复已拒绝理由不能同时宣称多个问题已修复；收据仍保留科学解决尚未验证。
- 顶层导出采用最新契约有效稿；另存latest与best-score历史文件及export-selection.json，不按一次高分悄悄恢复旧协议。
- JSON与报告保存精确字节。报告单独保存哈希，避免JSON不变而MD改动时覆盖历史报告。

## 验证与限制

本次回归测试使用合成模型返回值和本地服务，验证评分输入、结构拒绝、汇总、版本门控、修订定位与导出。测试不会调用付费模型或替历史稿重新评分。

确定性权重不使模型意见自动正确，target_fields也只验证对应字段变化。数学正确性、原文语义支持、创新性和真实实验仍需独立科学审查；不通过增加分项就宣称问题全部解决。
