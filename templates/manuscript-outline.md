# 证据驱动的论文骨架

先填写 claims.md 并完成结果审计，再起草正文；此模板不生成事实或授权投稿。

## 标题与摘要

只写被证据支持的研究范围、方法、结果与限制。每个数字附内部 claim ID，投稿前转换为正确图表引用。

## 问题与相关工作

问题边界、最近工作、不同之处与尚未验证的创新候选。每条引用记录实际支持的句子及原文定位。

## 方法

明确假设、输入、算法、参数、成本、实现与可复现的版本；避免用流程图替代关键定义。

## 实验

数据许可与版本、预处理/切分、强基线、信息和预算公平性、冻结指标、种子、独立统计单位、区间方法与停止规则。

## 结果

仅从真实运行制品生成表图。记录主比较、消融、失败、负结果、不确定性和协议偏离。区分开发探索与确认性评价。

## 讨论与限制

支持了什么、不支持什么、不能外推到哪里；比较替代解释。机制结论与性能结论分别举证。

## 可复现性、伦理与 AI 使用披露

代码/数据/环境/许可证可用性；隐私和潜在危害；使用的模型与版本、参与步骤、人工审查方式，以及目标 venue 的适用要求。

## 提交前审查

- [ ] 每条定量结论关联真实 run ID 和制品
- [ ] 引用已核对且支持附近句子
- [ ] 基线与候选的成本与可用信息可比
- [ ] 没有隐藏失败、挑种子或更换主指标
- [ ] 没有把草稿、仿真、模型预测或作者宣称当实测
- [ ] 负责人已批准披露范围与对外提交
